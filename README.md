# Zelvira Theme

Premium dark Shopify theme for glow AirPods / iPhone cases (RF audience).

## Connect to Shopify
1. Online Store → Themes → Add theme → **Connect from GitHub**
2. Repo: `abrorismurzaev2-cpu/zelvira-theme`
3. Branch: `main`
4. Preview → Publish

## Structure
Valid Online Store 2.0 theme: sections, JSON templates, section groups, CSS assets.
